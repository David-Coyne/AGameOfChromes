⚠️

Don’t open index.html directly

Chrome blocks the game scripts on file:// (CORS). Enter / Fullscreen / Keyboard Lock will not work reliably from a double-clicked HTML file.

Do this instead:

  1. Double-click run.bat in this folder (starts a local server)
  2. Or open http://localhost:8080/ after the server is running

Why: browsers treat local files as an opaque origin, so module/script loading and Keyboard Lock fail.
